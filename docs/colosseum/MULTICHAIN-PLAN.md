## Design
### packages/chains (@settlekit/chains; deps viem, @settlekit/arc)
- `registry.ts`: `EvmChainKey = ethereum|base|arbitrum|robinhood|hyperevm|tempo|arc`; `EvmChainSpec {key, env, chainId, caip2, name, defaultRpcUrl, explorerTx(hash), token{symbol,address,decimals}, minConfirmations, label?: "testnet"|"bridged"}`; `EVM_CHAINS` {mainnet,testnet} from the table; Arc re-exported from packages/arc chains.
- `evm-verifier.ts`: refactor (not fork) packages/arc client — `EvmRpc` alias re-exported by arc; arc tests stay green. Rules: (a) RPC `eth_chainId` == spec.chainId else throw (fix Arc ignoring chainId); (b) receipt success; (c) Transfer log from spec token address, to == payTo, value ≥ expected; (d) confirmations ≥ min; (e) block timestamp ≥ session createdAt − 120s; (f) global txHash uniqueness → 409; (g) optional payer binding when session has payerAddress; (h) Tempo optional memo == keccak256(sessionId). Use viem chain objects for formatters.
- `caip.ts`, `tx-hash.ts`, `address.ts` (browser-safe): EVM `^0x[0-9a-fA-F]{64}$` lowercased; Solana base58 64–88 verbatim; Zcash `^[0-9a-f]{64}$` lowercased. `isValidPayTo`: viem isAddress (strict checksum if mixed case), reject zero address; Solana base58; Zcash via @settlekit/zcash.
- `env.ts` `loadEvmChains(env)`: `SETTLEKIT_CHAIN_ENV=mainnet|testnet` (default testnet), `<KEY>_NETWORK`, `ENABLED_EVM_CHAINS=...` (others fail closed), `<KEY>_RPC_URL`, `<KEY>_MIN_CONFIRMATIONS`; no token override in production.
- `PaymentNetwork = solana|base|arc|ethereum|arbitrum|robinhood|hyperevm|tempo|zcash`. X402Network unchanged. CAIP-2 `eip155:<id>`; Zcash internal `zcash:mainnet|testnet` (non-standard, documented). Asset symbol from registry (USDC / USDG / USDC.e / pathUSD / ZEC).

### packages/zcash (@settlekit/zcash; no new deps)
`network.ts` (t1/t3 mainnet, tm/t2 testnet; blockchair tx URL), `address.ts` (base58check + 2-byte prefix; reject u1/zs "shielded not yet supported"), `quote.ts` (PriceSource, coinbase/kraken with injected fetch; `lockQuote` → rate, source, zats = ceil(usd/rate·1e8)+tag, expiresAt 15 min; reject >3% divergence/stale), `tag.ts` (sha256(sessionId) mod 10000, bump on collision), `zip321.ts` (no memo for t-addr, 8-dp trimmed), `explorer.ts` (`ZcashExplorer` interface + `createBlockchairExplorer`; 402/429/435 → retry later, never success), `verify.ts` `verifyZcashTransparent` (mined, outputs to payTo ≥ expected or == when exact, confirmations, blockTime ≥ notBefore, > expiresAt+10min → `late` manual review), `find-payment.ts` (exact-amount match over recent txids). Session JSON `settlementQuote?: {asset:"ZEC", amountBase, decimals:8, rate, source, lockedAt, expiresAt}`.

- API: `config/env.ts` → loadEvmChains + zcash block (keep `BASE_RPC_URL` alias); `config/integrations.ts` verifiers per enabled chain + zcash, chain-id assertion at boot; `routes/payment-verification.ts` normalizeTxHash from chains, OnChainCheck + notBefore/payer/expectedBase; `routes/checkout-sessions.ts` per-network payTo validation, acceptedNetworks/payToByNetwork, zcash quote lock; `routes/payments.ts` network-aware hash validation.
- Checkout: `lib/tx-hash.ts` re-export; `lib/verify-payment.ts` exhaustive switch (EVM via `lib/evm.ts` runtime, zcash via `lib/zcash.ts`); `lib/store.ts` notBefore = session.createdAt; `lib/format.ts`; routes `[sessionId]/network` (POST, only while open & unpaid), `[sessionId]/evm/params`, `[sessionId]/zcash/{uri,status}` (60s cache per payTo); `components/NetworkPicker.tsx`, `EvmPay.tsx` (EIP-6963 discovery, eth_requestAccounts, POST payer, wallet_switchEthereumChain/4902 add, viem writeContract transfer, poll confirm; manual hash fallback), `ZcashPay.tsx` (uqr QR, copy address/exact amount, quote countdown, polling, paste-txid fallback, "transparent payment, visible on-chain" note); page picks SolanaPay|EvmPay|ZcashPay; next.config transpilePackages.

- Env: `SETTLEKIT_CHAIN_ENV`, `ENABLED_EVM_CHAINS`, `{ETHEREUM,BASE,ARBITRUM,ROBINHOOD,HYPEREVM,TEMPO}_{RPC_URL,NETWORK,MIN_CONFIRMATIONS}`, `ZCASH_ENABLED`, `ZCASH_EXPLORER_URL`, `BLOCKCHAIR_API_KEY?`, `ZCASH_MIN_CONFIRMATIONS=3`, `ZCASH_QUOTE_TTL_SEC=900`. Update render.yaml + .env.example.
